# 使用指南

## 运行前提

按 [安装与接入](installation.md) 加载技能及所需资源。完整流程需要文件读取、Python 执行与图像查看能力。调用语法由使用的工具决定；下文采用通用自然语言请求。

## 输入与交付

| 模式 | 必要输入 | 可选要求 | 交付 |
|---|---|---|---|
| 图表生成 | 数据、字段含义、单位、比较目标 | 尺寸、字体、语言、格式、期刊规范 | 图表、脚本、配置、处理记录 |
| 图表审查 | 图片与用途 | 图注、原始数据、目标规范 | 问题清单、修改建议、核验范围 |
| 代码改进 | 绘图脚本及其输入数据 | 保留项、修改项、输出尺寸 | 新版脚本、图表、变更说明 |

文件可通过附件或工具可访问的路径提供。CSV 可直接读取；Excel 需指定工作表后转换。仅提供代码而缺少输入数据时，可以审阅代码，但不能完成运行验证。

## 图表生成

```text
使用 research-figure，根据 results.csv 比较方法 A 和方法 B 的准确率（%）。
第一列为实验条件，method_a、method_b 为各方法结果。
用于学术报告，使用中文标签，交付 PNG、PDF 和可复现代码。
```

处理流程：读取数据 → 核对字段、单位与样本 → 选择图形 → 执行绘图 → 检查导出图像 → 交付文件及处理记录。影响图义的信息缺失时先补充；未指定排版时可使用报告默认配置。

| 图形 | 数据结构 | 核对重点 |
|---|---|---|
| 时间序列 | 每行一个时刻，各列为不同序列 | 时间顺序、采样间隔、时区、缺失值 |
| 预测散点图 | 每行一个样本，含真实值与各模型预测 | 样本对齐、共同有效行、单位与坐标比例 |
| 指标对比 | 每行一个条件—方法的指标 | 指标定义、单位、可比性、误差线含义 |

列名无需固定。必要的结构转换和样本筛选应记录。误差线只采用提供且定义明确的数值。

## 图表审查

```text
使用 research-figure 审查附件图表，检查坐标轴、单位、图例、配色和字号。
按“位置—问题—依据—建议”列出结果，注明未核验内容。本次不重绘。
```

审查以实际可见内容为依据。没有原始数据时，不还原精确数值、不判断统计显著性。需要准确重绘时，应提供数据或绘图脚本。无法查看图像的模型只能审阅文字与代码，应明确说明视觉检查尚未完成。

## 代码改进

```text
使用 research-figure 修改 plot.py，所需数据已附上。
保留数据处理和指标计算，统一字体、图例与布局，图宽设为 90 mm。
另存新版脚本，输出图表和变更说明，不运行模型训练。
```

先检查输入及依赖，再运行绘图部分。未执行的脚本应标注为待验证；不能将代码生成描述为已完成出图。

## 迭代修改

在同一会话中补充修改要求，例如图例位置、输出语言、字号或跨图颜色一致性。仅修改外观时保留数据和统计口径。更换数据、重新选样本或改变聚合方式时，应明确指定。

## 输出与限制

默认输出 PNG、PDF/SVG、绘图脚本、配置及运行记录。记录包含输入位置、散列、依赖版本和缺失处理信息。SVG 保留可编辑文字，跨设备使用时可能需要相应字体。

三个内置入口以外的图形需要另行编写和验证代码。图表样式不等于投稿合规；有明确期刊要求时，应同时提供规范。测试范围见 [贡献指南](../CONTRIBUTING.md)。
