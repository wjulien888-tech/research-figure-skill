# 科研图表制作与检查：使用说明

`research-figure` 用来把已有实验数据做成图、检查已有图，或改进绘图代码。适用于不同学科的数值实验和模型比较，没有预设研究领域。

## 1. 从哪里开始

**在 Codex 对话框中使用。** 把文件作为附件提供，或告诉 Codex 可访问的本地文件路径，然后发送“用 research-figure……”加上你的需求。也可以在消息里直接写 `$research-figure`。这是一条聊天消息，不是终端命令。

请先按照 [README 的安装步骤](../README.md#安装到-codex) 安装技能。普通使用不需要打开 Python、填写 JSON 或手动运行脚本；读取文件、生成配置和执行绘图由 Codex 完成。

最短用法：

> 用 $research-figure 处理我附上的实验数据。我想比较方法 A 和方法 B 的表现，图用于组会。先看数据，缺少字段含义或单位时问我，再生成图和可复现代码。

官方说明支持在提示中明确指定技能，也支持按任务自动匹配；若安装后未被发现，可以重启 Codex。[OpenAI 技能说明](https://learn.chatgpt.com/docs/build-skills)

## 2. 按手里的材料选择一种用法

| 你手里有什么 | 需要提供什么 | 你会得到什么 |
|---|---|---|
| 实验数据，想画图 | CSV，或 Excel 及目标工作表；想比较什么；字段含义和单位；图的用途 | 图的预览、导出文件、可复现代码和处理说明 |
| 已有图，想检查 | PNG/JPG 等图片；图的用途；已有图注可一起提供 | 具体问题位置、原因、修改建议，以及无法核验的内容 |
| 绘图代码，想改图 | Python/Matplotlib 脚本及其读取的数据；想改的地方 | 新版脚本、新图，以及修改说明 |

图的用途可以只说“组会”“论文”或“答辩”。已知尺寸、期刊要求、配色或中英文字体偏好时再补充。第一次不必准备所有信息，Codex 会先读文件，只追问影响图义的缺口。

### 用法 A：提供数据，让它出图

**操作：** 提供数据文件 → 说明比较目标和用途 → 补充必要信息 → 查看图 → 继续提出修改要求。

可直接复制：

> 用 $research-figure 根据附件 results.csv 画实验结果图。第一列是实验条件，method_a 和 method_b 是两种方法的准确率，单位是 %。我要比较两种方法在不同条件下的表现，用于组会，使用中文标签。请选择合适图形，交付 PNG、PDF 和可复现代码；不要修改原始数据。

它会读取表格、判断数据结构，核对单位和样本，选择图形并执行绘图；生成后还要实际查看图片，检查标签、图例、遮挡和裁切，再交付结果。数据意义不明确时会先问清楚；排版要求未指定时可使用报告默认尺寸并说明。

**表格不需要使用固定列名。** 以下只是三种常见结构示意，数字均为演示值：

| 适合画什么 | 你的表格可以有哪些列 | 每一行代表什么 |
|---|---|---|
| 时间序列对比 | 时间、测量值、方法 A、方法 B | 同一时刻各序列的值 |
| 预测值与真实值散点图 | 样本编号、真实值、预测 A、预测 B | 同一个样本的真实值和各方法预测值 |
| 分条件指标对比 | 实验条件、方法名称、指标值 | 某种方法在某个条件下的一个指标 |

列的对应关系、必要的宽表/长表转换由 Codex 处理并记录。误差线需要你提供数值及含义，例如标准差；只有平均值时不会凭空补上误差线。

### 用法 B：提供已有图，让它检查

**操作：** 附上图片 → 说明用途 → 阅读问题清单 → 决定是否提供原始数据进一步修改。

可直接复制：

> 用 $research-figure 检查这张图，我准备放进论文。请检查坐标轴范围、单位、图例、颜色区分、字号和信息表达。按“问题位置—为什么有问题—怎么改”列出建议，并标明仅凭图片无法判断的部分。本次只检查。

这一步的主要交付是审查意见，不会必然产生一张新图。只有截图时，可以检查可见的表达问题，但不能确认原始数值、统计显著性或数据真实性。如果需要准确重绘，再提供原始数据或绘图脚本。

### 用法 C：提供代码，让它改图

**操作：** 提供绘图脚本和依赖的数据 → 说明想改什么 → 查看新版图与代码 → 继续调整。

可直接复制：

> 用 $research-figure 改进附件 plot.py。它读取的数据也已附上。请保留原有数据处理和指标计算，只调整字体、图例、配色和布局；用于论文，宽度设为 90 mm。另存新版脚本，交付修改前后的说明和新图，不运行模型训练。

只提供代码但未提供其读取的数据时，可以先检查和修改代码；能否运行验证，要看输入文件和依赖是否齐全。不会把未运行的代码称为已验证结果。

## 3. 交付后如何继续修改

直接在同一对话里描述变化即可，例如：

> 图例挡住了数据，移到图外；方法 A 在所有图中统一用蓝色实线。

> 改成英文标签，保留数据和坐标范围，另导出 SVG。

> 这张图用于答辩，请增大字号，并检查投屏时是否容易区分各方法。

不需要重新提交已经提供过的背景。你想更换数据、调整统计口径或重新选样本时，要明确说明；单纯改外观应保留原有数值与样本。

## 4. 默认交付内容与能力边界

出图任务通常包含 PNG 预览、PDF/SVG 矢量图、绘图脚本、配置和处理记录；可以按你的要求只保留部分格式。SVG 的文字可编辑，在另一台机器上打开时可能需要相应字体。

当前有三个可直接运行的绘图入口：时间序列对比、预测值与真实值散点图、分条件指标柱图。其他图形或复杂多面板可以由 Codex 编写或调整绘图代码，但需要逐项验证，不能当作已经覆盖的固定功能。

CSV 可直接读取；Excel 需指定工作表后转换。运行记录会保留输入文件位置、散列、依赖版本和缺失处理方式，便于复现。原始数据不会因为“美化”而被平滑、删异常或改写。

图表审查由 Codex 查看图片并结合规则完成，脚本不自动判定所有视觉问题，也不能保证满足某期刊全部投稿规范。投稿时应提供具体刊物要求。
