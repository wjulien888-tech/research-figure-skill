# 科研图表制作与检查

把已有实验结果变成清晰、准确、可复现的图。用于数值实验中的模型比较、时间序列与条件分析；不要预设用户所属学科或数据单位。RSS 指南提供表达依据；SciencePlots 提供样式，不能单凭套用样式宣称通过检查或符合某期刊全部要求。

## 按输入进入工作

- **数据 → 图**：读取字段、单位、样本与时间范围，结合用户想回答的问题选图。第一版的三个可执行入口见 [绘图输入与命令](references/plotting.md)。若文件是 Excel，先用可用文件工具导出用户指定的工作表为 CSV，记录工作表与转换步骤。
- **已有图 → 审查**：先看图，再读 [审查规则](references/review-rules.md)。只有截图时，报告能观察到的问题；不推断原始数值、样本量、统计显著性或数据真实性。准确重绘需要原始数据或代码；不能从像素猜造数据。
- **已有代码 → 改进**：先阅读绘图和数据处理部分，保留用户的计算口径与授权范围。通常另存新版。先确认依赖和输入再运行；不要因为改图就运行训练、重新优化模型或整套长实验。

复用用户已经给过的背景。只补问影响图义的缺口，如单位、目标比较、误差线含义、数据是否对齐。尺寸或风格未指定可采用 `report` 配置并说明；不要把数据含义当作排版默认值猜测。

## 绘图与检查

1. 根据 [审查规则](references/review-rules.md) 选择相关检查。区分原始事实、计算结果与视觉判断。保持数值和样本口径，显式记录筛选、聚合、缺失处理和单位转换。不得为了更好看而平滑、删异常或制造误差线。
2. 使用 SciencePlots。读 [实现说明](references/plotting.md) 获取配置和 helper 用法。先尝试技能目录下 `.venv/bin/python`（Windows 为 `.venv/Scripts/python.exe`），否则检查当前项目解释器。仅在缺少依赖时，按当前环境授权在隔离环境安装 `requirements.txt`；不要改全局 Python。缺少 SciencePlots 时说明并解决依赖，不假称已经应用其样式。
3. 根据需要运行 `scripts/plot_csv.py --config ...`，或者用 `scripts/figure_tools.py` 创建自定义 Matplotlib 脚本。命令行适用于简单宽表/长表；复杂多面板、已有脚本优先按用户数据结构编写小脚本，不强行转成不合适的固定图形。
4. 在最终阅读尺寸下实际查看导出的 PNG，检查遮挡、裁切、图例、中文/负号缺字及缩放后可读性。读运行警告和 JSON 记录。对于 PDF/SVG，保留矢量输出；要求精确投稿尺寸时额外检查画布尺寸。脚本成功只证明渲染完成。
5. 有数据时对照字段、样本量和图中数值；只有图片时写明未核验部分。自动脚本没有全面检测文字碰撞、色盲可读性、科学结论或期刊要求，不把它的运行记录称为通过审查。

## 三类图的关键约束

- **时间序列**：核对时间顺序、频率、时区、预测步长和单位。不能把错位的预测与真实值相连。缺失点保留断线；已知采样间隔时标出缺口，不能默默插值。必要时全时段图配明确标出的局部窗口。
- **预测值—真实值**：方向标注清楚；默认横轴真实值、纵轴预测值，统一范围、等比例和 `y=x` 参考线。多个模型默认共同有效样本；报告因缺失排除的行数。对单一物理量比较才使用这套约束。
- **场景指标**：确认指标定义、单位、方向和评估样本可比。柱图以零为基线；含负值时向两侧展开。不同单位或含义的指标分图。误差线只使用用户提供且已解释的值，不把跨场景差异当重复实验不确定性。

## 交付

依请求交付 PNG 预览、PDF/SVG、绘图脚本及配置、输入数据定位/散列与必要的处理说明。保留用户指定格式；只要求审查时不强行重绘。

结论简洁说明：改了什么、为什么、实际检查了什么、哪些尚不能确认。用户需要图注或替代文字时，描述可见结果，不补写未经验证的优越性或显著性。若输入是模拟数据，图内和说明都显式标注。
